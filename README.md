## xrwvm-fullstack_developer_capstone

**Repository name:** xrwvm-fullstack_developer_capstone

**Project name:** Best Cars Dealership - Full Stack Django and React Application

## Description
A full stack web application for browsing car dealerships and their reviews.
It uses a Django backend, a React frontend, and a Node/Express service with MongoDB for dealer and review data.

## Features
- Home, About Us and Contact Us pages
- User registration, login and logout
- Dealer list and dealer details
- Dealer reviews
- Car makes and models
